# 中文单栏重排工作流

状态：实验策略，ZK-Tracer 样稿已经跑通。本文档用于区分人工调参、确定性排版算法和 DeepSeek 的职责，并记录后续固化路径。

## 1. 职责边界

### DeepSeek 负责

1. 按语义单元翻译正文、标题、图题和表题。
2. 保留术语、公式、引用编号、单位和受保护标记。
3. 在 PDF 编译完成后执行视觉终审，报告裁切、重叠、错误窄栏、语义顺序和明显版式问题。

DeepSeek 不决定字号、页边距、行距、首行缩进、标题段前距或图表宽度。这些值必须由确定性的排版算法产生，保证同一输入可复现。

### 本地排版算法负责

1. 将英文一栏、两栏或混合栏正文统一重排为中文单栏正文。
2. 根据语义类型选择标题、作者、机构、正文、图表、公式、图题和参考文献样式。
3. 维护每个翻译语义单元的 `pp-unit` 标记，使阅读器仍能进行中英文对应和高亮。
4. 编译 Typst PDF，执行内容门禁和逐页视觉验收。

## 2. 当前单栏样式参数

参数的正式来源是 `src/core/typst/template.ts` 中的 `SINGLE_COLUMN_TYPOGRAPHY`。

| 项目 | 当前值 | 目的 |
| --- | ---: | --- |
| 正文字号 | 10.5pt | 保持论文密度，同时提高中文可读性 |
| 正文行距 | 1em leading | 为逐段高亮和双侧对应留出垂直空间 |
| 段间距 | 0.42em | 区分自然段，不依赖空行 |
| 首行缩进 | 2em，含标题后的首段 | 符合中文连续正文阅读习惯 |
| 一级标题 | 13pt，段前 14pt，段后 8pt | 明确章节层级并与正文分离 |
| 二/三级标题 | 11.5pt，段前 10pt，段后 7pt | 保持层级差异并避免紧贴正文 |
| 标题、作者、机构 | 居中 | 形成清晰的首页信息区 |
| 图、表、展示公式、图题 | 居中 | 避免单栏中的视觉偏移 |
| 参考文献 | 8.5pt、悬挂缩进 | 提高编号扫描效率并控制页数 |

## 3. 从论文到最终 PDF

1. 解析英文 PDF，生成页面、文本块、语义单元和不可变资产。
2. 为每个语义单元分配稳定 ID，并建立英文坐标到语义单元的对应表。
3. 调用 DeepSeek 翻译；命中缓存时复用经过内容门禁的译文。
4. 当 `targetLayoutPolicy=single-column` 时：
   - 所有普通正文区域变为单栏自然流；
   - 横向图组、并排对比图和成组表格可以保留网格；
   - 单个图表按内容宽度适度放大，但不得超过正文宽度；
   - 正文、标题、图题和参考文献分别应用自己的排版参数。
5. 编译 Typst，并保留所有 `pp-unit` 链接标记。
6. 执行内容门禁：页数非零、关键章节存在、语义标记没有丢失、不可变资产哈希正确。
7. 将每页渲染成 PNG，逐页检查标题间距、首行缩进、图表居中、裁切、重叠、空白页和参考文献可读性。
8. 有 API 时调用 DeepSeek 视觉终审；它是第二检查者，不覆盖确定性排版参数。
9. 只有本地门禁和视觉终审都通过，才允许保存任务结果或部署。

## 4. 本轮 ZK-Tracer 调试记录

1. 原始英文为 8 页两栏，首次中文单栏样稿为 9 页。
2. 修复第 7 页两个并排表格被错误放大导致的越界。
3. 将标题、作者、机构、图表、公式和图题改为对应的居中规则。
4. 正文增加 2em 首行缩进，并拆分被合并的一级/二级标题。
5. 正文行距增加到 1em，样稿自然增加到 10 页；参考文献继续使用独立紧凑行距。
6. 修复公式截图包含下一行正文的旧裁切错误，样稿中重新排出该公式。
7. 根据第二轮视觉反馈，将一级标题段后距增加到 8pt，二/三级标题段后距增加到 7pt。

## 5. 修改算法时的验证清单

- 不用截图坐标或论文名称硬编码正式算法；样稿适配脚本只能用于验证。
- 任何排版参数修改都要增加或更新单元测试。
- 至少选择一篇一栏论文和一篇两栏论文做回归。
- 必须渲染全部页面；只检查首页不能作为通过依据。
- 检查正文首段、连续段落、标题后的首段、跨页续段、图表前后段落和参考文献。
- 确认中英文对应依赖语义 ID，而不是相同页码或相同行号。
- 记录输入论文、译文缓存版本、样式参数、页数变化、发现的问题及修复结果。

## 6. 相关实现

- `scripts/build-single-column-typst-prototype.mjs`：ZK-Tracer 缓存样稿适配器，仅用于实验验证。
