## 算法规格(即 Sprint 1 的 TS 实现基准)

```
getTextContent() items
  → 每 item 的 transform 经 viewport 矩阵换算为视口坐标(x,y,w,h)
  → y 容差 4px 聚成行
  → 行内按 x 排序,x 间隙 > 24px 拆成不同栏的行
  → 每行分类:span>0.5W 或 (span>0.38W 且居中) = full;
             中点 > 0.5W = right;否则 left
  → 阅读顺序:full(y↑) → left(y↑) → right(y↑)
```
