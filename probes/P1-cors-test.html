连接参数

测试内容:① 浏览器预检(OPTIONS);② 真实最小请求(max_tokens=1);③ 响应头中 Access-Control-Allow-Origin 检查。
Key 安全:除非勾选保存,Key 只在本页内存中,刷新即消失;本页无任何网络请求去向 DeepSeek 之外的服务器。

判定标准

① 预检与真实请求都成功,且 Access-Control-Allow-Origin 存在 → 通过:纯前端直连可行,不需要代理
② 请求被浏览器拦截 / 头缺失 / 报 CORS 错误 → 不通过:启用"可选代理地址"方案
③ 网络不可达 / 401(Key 错)→ 与 CORS 无关,按提示修正后重测
