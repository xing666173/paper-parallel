# P3 探针报告 —— 块级分页器原型

状态:**通过(双栏 / 单栏 / 混合三种版式全部通过)**

## 探针目标(Sprint 0 第 3 项)

验证自研"块 → 栏 → 页"分页算法的可行性,证明可以不用 CSS columns 完成论文级排版:

- R4 版式继承:单栏 / 双栏 / 混合(标题摘要通栏 + 正文双栏),页数自然延伸
- R5 块级保序:图 / 表 / 公式钉在相邻正文块之间的相对位置,不漂移
- 原子块(图 / 表 / 公式)不劈开;文字块允许按句边界跨栏 / 跨页断块
- 屏幕渲染与导出打印共用同一布局数据

## 验证方法

自包含 HTML(零依赖),内置:
- 确定性假数据(种子可复现):33 个块,含 7 个图/表/公式原子块,其中表 3 刻意超高(1180px > 页高 986px)测试降级
- 真实测量:隐藏测量容器 + 浏览器断行 → 每块高度
- 自检:装填后按(页, 栏, y)重建阅读顺序,与原始块序比对

在系统 Chrome(1200px 视口)对三种版式逐一截图回归。

## Debug 记录(本次探针发现并修复 6 个 bug)

1. **JS 语法错误**:while 块内 `const page` 重复声明 → 整个脚本不执行(首屏空白)。已修复。
2. **title/authors 误判为原子块**:读取不存在的 atomicH → NaN 污染布局。已修复,归入文字流块。
3. **frontMatter 在混合版式落入左栏**:摘要/关键词没放通栏区。已修复,新增页顶 `full` 通栏栈。
4. **双栏模式标题不通栏**:标题/作者/摘要按左栏宽排版。已修复,frontMatter 一律进 `full` 通栏栈,正文双栏起点对齐通栏底部。
5. **块序倒置(核心)**:图块放不下左栏余量时直接跳右栏顶,导致"左栏底部的后续正文"在阅读顺序上早于该图。已修复:跳右栏顶时关闭左栏余量(留白),后续文字从图下继续——保证块序严格不变。
6. **单栏模式原子块落到新页时硬编码 left 栏**:渲染丢失且读序错乱。已修复,按页模式选栏。
7. **文字片段可能越界半行**:列余量 < 一行高时仍塞文字。已修复,余量不足一行高即视为满,且字符级切分不再产生空片段。

## 结论与对主工程的约束

- 分页算法可行,直接照此实现 `src/core/paginate/` 的 TS 版本。
- **严格保序规则定为正式规则**:原子块跳右栏顶时必须关闭左栏余量(允许留白);这是"图文相对位置不漂移"需求下的确定性选择。
- 假数据与三种模式的回归截图可作为后续 TS 实现的基准对照。
